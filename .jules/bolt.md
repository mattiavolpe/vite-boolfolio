## 2024-05-24 - Global Scroll Listener Memory Leak and Layout Thrashing in AppHome.vue
**Learning:** The `AppHome.vue` component previously attached an unthrottled `scroll` listener to the global `window` object in `mounted()`, repeatedly querying `getClientRects()[0]` to determine the active header style. This not only caused layout thrashing (synchronous DOM layout calculations) on every scroll tick but also created a memory leak because the listener was never removed in `unmounted()`.
**Action:** Always throttle continuous global events (like `scroll` or `resize`) using `requestAnimationFrame`, mark them as `{ passive: true }` to unblock the main thread, prefer `getBoundingClientRect()` over `getClientRects()`, and strictly enforce event cleanup in the `unmounted()` hook.
