## 2024-05-24 - Unthrottled scroll listeners cause memory leaks and layout thrashing
**Learning:** Attaching `scroll` listeners directly in a component's `mounted` hook without throttling (e.g., via `requestAnimationFrame`) and without cleanup in `unmounted` leads to severe memory leaks when navigating between routes. Furthermore, omitting `{ passive: true }` and reading layout properties like `getClientRects()[0]` directly inside the unthrottled listener causes layout thrashing and scrolling jank.
**Action:** Always extract scroll listener logic into a separate method, throttle it using `requestAnimationFrame`, add `{ passive: true }` during registration, use `getBoundingClientRect()` instead of `getClientRects()[0]`, and importantly, remove the listener in the component's `unmounted` hook to prevent the memory leaks across the SPA.
