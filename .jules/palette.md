## 2024-09-24 - Add accessible form loading states
**Learning:** When form inputs correctly use `required` and `aria-required`, and submit buttons convey a loading state with `disabled` and `aria-disabled` attributes, it ensures assistive technologies can effectively communicate form expectations and processing status to users.
**Action:** Always ensure interactive elements convey their current state (e.g. disabled, loading) and form inputs clearly define constraints natively (using proper type attributes) and explicitly via ARIA for maximum accessibility.
