## 2024-05-08 - Passive Scroll Listeners and getBoundingClientRect
**Learning:** Found an inline, non-passive `window.addEventListener('scroll')` in `AppHome.vue` that used `getClientRects()[0]`. `getClientRects()` can cause layout thrashing and is slower than `getBoundingClientRect()`. Additionally, omitting `{ passive: true }` blocks the main thread during scroll events, hurting scroll performance. Furthermore, failing to remove global window event listeners in a Vue component's `unmounted` hook can cause memory leaks and execution of logic on unrelated routes.
**Action:** Always extract global event listeners to named methods, attach them with `{ passive: true }` if they don't call `preventDefault()`, clean them up in the `unmounted` lifecycle hook, and prefer `getBoundingClientRect()` over `getClientRects()[0]` for better DOM read performance.
