## 2026-06-01 - Vue Component Memory Leaks from Global Event Listeners
**Learning:** Adding global event listeners (like `window.addEventListener('scroll')`) inside a Vue component's `mounted` hook without removing them in `unmounted` causes memory leaks and duplicate event firing when navigating between routes. The app architecture uses a simple global state for DOM elements, requiring null checks.
**Action:** Always store the event handler reference and clean it up using `window.removeEventListener` in the `unmounted` lifecycle hook. Also, use `{ passive: true }` for scroll events to improve scrolling performance, use `getBoundingClientRect()` instead of `getClientRects()[0]` for efficiency, explicitly throttle with `requestAnimationFrame`, and add null-safety checks when accessing DOM elements from global state.
