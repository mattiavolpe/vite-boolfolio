## 2024-05-14 - Global State Element Ref Leak & Scroll Event Jank
**Learning:** The application heavily relies on storing DOM element references in a global reactive `state` object (e.g., `state.footerEl`) via child components to enable centralized scroll tracking in `AppHome.vue`. Attaching an anonymous scroll listener directly reading these global reactive properties causes significant layout thrashing. Furthermore, failing to unbind these global listeners causes severe memory leaks because the anonymous functions hold closures over the global state, preventing garbage collection across route changes.
**Action:** Always extract scroll listener callbacks to bound component methods, throttle them with `requestAnimationFrame`, initialize related tracking variables non-reactively in `created()`, and strictly unbind the listener in `unmounted()` to prevent memory leaks and jank.
