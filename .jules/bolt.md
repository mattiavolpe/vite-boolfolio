## 2024-04-11 - [Vue Global State Lifecycle Synchronization]
**Learning:** [When child components register their root elements into a global state object (e.g., `state.footerEl` in `mounted()`), parent views consuming those elements (e.g., in a global `scroll` event listener) can encounter null reference exceptions because the order of component mounting and event firing isn't strictly guaranteed. Furthermore, relying on Vue's reactivity system to track purely internal variables like scroll handler references or animation frame IDs introduces unnecessary overhead.]
**Action:** [Always include defensive null checks (`if (!state.element) return;`) before accessing DOM properties on globally stored elements. When defining global event listeners in Vue components, initialize non-reactive state in `created()` to bypass reactivity overhead, and always explicitly unbind the listener and cancel any pending `requestAnimationFrame` IDs in the `unmounted()` hook to prevent memory leaks.]
