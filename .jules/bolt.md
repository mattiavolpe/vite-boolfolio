## 2024-04-13 - [Throttle Component Scroll Events]
**Learning:** Attaching unbound, unthrottled `scroll` event listeners to the global `window` object within Vue components can degrade performance (layout thrashing) and lead to memory leaks when navigating between routes if not unmounted. Additionally, properties like `getClientRects()[0]` can cause runtime crashes if the component or element hasn't fully rendered.
**Action:** Always wrap heavy layout computations within `requestAnimationFrame` using a `ticking` flag to throttle them. Use `{ passive: true }` when adding global scroll listeners. Most importantly, ensure `removeEventListener` and `cancelAnimationFrame` are called in the `unmounted` lifecycle hook, and use `getBoundingClientRect()` with null checks for safer element measurements.
