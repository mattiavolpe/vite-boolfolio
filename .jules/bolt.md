## 2023-10-27 - Unthrottled Scroll Listeners with Synchronous Layout Queries
**Learning:** In Vue SPAs (like AppHome.vue), anonymous functions attached to global window scroll events without cleanup cause memory leaks across routes. Calling `getClientRects()` or `getBoundingClientRect()` synchronously inside these raw scroll handlers forces layout recalculations (thrashing) multiple times per frame, severely degrading scrolling performance.
**Action:** Always extract scroll handlers into bound component methods, throttle them using `window.requestAnimationFrame()`, add `{ passive: true }` to the event listener, and ensure they are properly removed in the `unmounted` lifecycle hook. Additionally, always add null checks before reading DOM properties, as elements might not exist immediately after mounting or when navigating away.
