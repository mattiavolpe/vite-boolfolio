## 2024-05-13 - Optimize Scroll Event Listeners in Vue Components
**Learning:** Found an inefficient global `scroll` event listener in `src/views/AppHome.vue` that wasn't properly throttled, used `getClientRects()[0]` for coordinate retrieval, lacked `{ passive: true }`, and failed to clean up after itself. These anti-patterns cause unnecessary main-thread blocking, layout thrashing, and memory leaks as the component mounts and unmounts.
**Action:** Always throttle scroll listeners with `requestAnimationFrame`, add `{ passive: true }` when adding the listener, use `getBoundingClientRect()` over `getClientRects()[0]`, and importantly, extract the handler to a method so it can be correctly removed via `window.removeEventListener()` in the `unmounted` lifecycle hook, along with canceling any pending animation frames.
