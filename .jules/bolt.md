## 2026-03-27 - [Throttling Scroll Layout Thrashing & Memory Leaks in Vue App]
**Learning:** The application manages DOM references for scroll effects via a centralized `state.js` reactive object. The parent view (`AppHome.vue`) accesses these element refs to read `getClientRects()` synchronously inside an unthrottled global window `scroll` event. This triggers severe layout thrashing (synchronous layout reflows) across every browser frame. Furthermore, not removing this listener on component unmount causes a memory leak and "zombie" layout queries on other routes.
**Action:** Use `requestAnimationFrame` to throttle scroll event listeners that perform layout measurements like `getBoundingClientRect`/`getClientRects()` or DOM manipulations. Always extract global event listeners to named methods and remove them in the component's `unmounted` (or `beforeUnmount`) hook.
