## 2025-02-12 - Scroll Performance and Event Cleanup
**Learning:** Found an anonymous, non-passive global scroll event listener using `getClientRects()[0].y` tied to global element references stored in Vue state (`state.footerEl` etc). This combination blocks the main thread during scroll, risks null references when navigating to pages where elements aren't rendered, and lacks cleanup causing memory leaks and repeated listener attachments across route transitions. Furthermore, `getBoundingClientRect()` is substantially more performant than `getClientRects()[0]` for coordinate retrieval.
**Action:** When implementing global scroll/wheel/touchstart handlers, always: 1) Refactor to bound methods to allow cleanup in `unmounted`, 2) Attach with `{ passive: true }`, 3) Use `getBoundingClientRect()` over `getClientRects()[0]`, and 4) Add existence checks before accessing DOM references that might unmount on different views.
