## 2024-07-10 - Contact Form Semantic Validation and Loading State
**Learning:** In Vue apps with asynchronous forms, combining correct HTML5 input types (`type="email"` instead of `type="mail"`), native `required` attributes, and managing an `isSending` state provides robust out-of-the-box accessibility and feedback. Adding visual 'required' asterisks (`*`) wrapped in `<span aria-hidden="true">` ensures sighted users see the requirement without redundant announcements for screen reader users. Clearing the form inputs in the promise resolution prevents accidental duplicate submissions.
**Action:** Consistently use native HTML5 validation and async loading states (`:disabled="isSending"`) in form submissions, ensuring visual indicators are correctly hidden from assistive technologies.
