## 2024-05-24 - Semantic Form Inputs and Feedback State
**Learning:** Adding semantic HTML validation with native input types and visually explicit required indicators alongside a disabled submitting state provides an easy, low-overhead win for form accessibility and UX without needing complex custom validation logic.
**Action:** Always verify form inputs for correct types (e.g. `email` over `mail`), append `aria-hidden` required asterisks, and bind submit buttons to loading states.
