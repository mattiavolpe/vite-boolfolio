## 2026-05-29 - Global scroll event listeners performance and cleanup
**Learning:** Adding a global `scroll` event listener in a Vue component's `mounted` hook without `requestAnimationFrame` throttling, passive `{ passive: true }` listener options, and proper cleanup via `removeEventListener` in `unmounted` leads to severe performance degradation due to main thread blocking and memory leaks across route navigation. Also using `getClientRects()[0]` is less efficient than `getBoundingClientRect()`.
**Action:** Always optimize global scroll listeners by using `requestAnimationFrame`, `getBoundingClientRect()`, and passing `{ passive: true }`. Ensure event listener references are stored and properly removed in the component's `unmounted` hook to prevent memory leaks. Also make sure to add null safety checks before accessing DOM elements stored in a global state object.
