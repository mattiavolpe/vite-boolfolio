## 2024-05-03 - Improved Contact Form UX and Validation
**Learning:** In Vue/Bootstrap applications, failing to use standard HTML5 form attributes (like `type="email"` and `required`) strips out native browser validation, creating a poor experience, especially on mobile devices where the keyboard doesn't adapt to the expected input. Furthermore, asynchronous actions (like submitting the form via Axios) *must* include explicit UI feedback. When a button doesn't disable and change text (e.g. to "Sending...") or when success/error alerts are missing, users often click multiple times or are left confused about whether their action succeeded.
**Action:** Always verify that native HTML5 input types and attributes (`required`, `type="email"`, etc.) are used for forms. For any async operation (API requests), mandate the inclusion of an `isSubmitting` state to disable the primary action button, and a clear `submitStatus` (success or error) string state linked to visible UI alerts to provide definitive feedback.
