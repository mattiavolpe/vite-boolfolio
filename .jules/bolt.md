## 2024-05-24 - Vue Global Event Listener Performance and Safety
**Learning:** Attaching global event listeners (like `window.addEventListener('scroll')`) directly in a Vue component's `mounted` hook without `unmounted` cleanup causes memory leaks and unintended cross-route execution. Additionally, accessing DOM elements from a global state (`state.headerEl`) within these listeners can cause crashes if the elements haven't mounted yet or the current route has changed. Calling `getClientRects()[0]` on potentially unrendered elements throws errors.
**Action:** Always clean up global listeners using `window.removeEventListener` and cancel `requestAnimationFrame` using `cancelAnimationFrame` in the component's `unmounted` hook. Add null checks for referenced elements. Use `getBoundingClientRect()` for safer DOM measurements. Add `{ passive: true }` to scroll/touch listeners for better scroll performance. Initialize non-reactive variables (like `ticking`) in `created()` to avoid tracking overhead.
