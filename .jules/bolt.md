## 2024-05-24 - Vue Global Event Listener Memory Leak
**Learning:** Found a severe performance anti-pattern in `src/views/AppHome.vue` where a global `window.addEventListener('scroll')` was registered in `mounted()` without throttling, and crucially, without being removed in `unmounted()`. This causes a memory leak and redundant main-thread executions every time the route is visited and left. Additionally, it accessed global state DOM elements (like `state.footerEl`) without null checks, which can throw errors if those components are not rendered.
**Action:** When adding global event listeners (like scroll/resize) in Vue components, ALWAYS extract the handler function, use `{ passive: true }` and `requestAnimationFrame` for performance, and ALWAYS remove the listener in the `unmounted()` lifecycle hook. Use optional chaining for DOM element access.
