## 2024-04-17 - Async Form Submissions Feedback
**Learning:** For asynchronous form submissions in Vue (via Axios/Fetch), standard UX/Accessibility conventions require implementing an `isSending` state to disable the submit button and visually indicate the operation is in progress (e.g., changing text to "Sending..."). Additionally, providing accessible post-submission feedback requires an explicit feedback block equipped with `role="status"` and `aria-live="polite"` so screen readers proactively announce the success or failure status upon completion. Relying on native HTML5 validation constraints (e.g., `required`, `type="email"`) ensures immediate feedback before executing the network request.
**Action:** When implementing async form submissions, always provide native validation requirements along with immediate loading feedback (disabling button) and an `aria-live="polite"` block to display post-submission outcomes for inclusive user experience.
