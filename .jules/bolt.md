## 2024-05-17 - Throttling Scroll Event Listeners in Vue with getBoundingClientRect()
**Learning:** The previous implementation used a synchronous `scroll` event listener on the `window` to apply header styling. This listener repeatedly called `element.getClientRects()[0].y`. `getClientRects()` throws a `TypeError` if an element is unmounted (returning an empty array), and performing synchronous heavy DOM reads like this during scroll events blocks the main thread, causing severe layout thrashing (jank) in a Vue 3 application.
**Action:** When implementing scroll-bound UI logic in Vue, ALWAYS wrap the bounding checks in `requestAnimationFrame()` to throttle them to the display's refresh rate. Additionally, use `getBoundingClientRect()` with optional chaining (`state.element?.getBoundingClientRect()`) which is safer against unmounted DOM elements, preventing `TypeError` crashes while still triggering reactivity efficiently. Track the animation frame ID directly on the component instance (e.g., `this._scrollTicking = false`) instead of `data()` to avoid unnecessary Vue reactivity overhead for internal tracking variables.
