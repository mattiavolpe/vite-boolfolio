## 2025-07-04 - Contact Form UX/Accessibility Improvements
**Learning:** The contact form initially lacked accessible visual indicators for required fields and proper HTML5 input types (used `type="mail"` instead of `type="email"` and `type="text"`), leading to poor semantics. It also lacked a loading state during the Axios POST request, which can cause duplicate submissions if the user repeatedly clicks "Send e-mail" while waiting for a response.
**Action:** Applied standard UX patterns: introduced `isSending` state to disable the submit button and show 'Sending...', corrected input types, added `required` attributes, and added `<span aria-hidden="true">*</span>` to labels for visually marking required fields without cluttering screen reader announcements. Used `.finally()` in Axios to reliably reset the loading state.
