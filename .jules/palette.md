## 2024-06-21 - Form Status Indicators and Accessibility Enhancements
**Learning:** Adding explicit status indicators (success/error alerts, disabled loading states with spinners) and semantic `required` attributes to form fields greatly improves the user experience by providing immediate feedback and clarity, especially for screen readers where visual cues alone might not suffice. Also fixing incorrect input types (`mail` to `email`/`text`) aids browser validation.
**Action:** When implementing asynchronous form submissions, manage a loading state (`isSending`) to disable the submit button during the request, and clear the form inputs upon successful submission while displaying a success message. Always use standard input types and semantic HTML attributes like `required` and `aria-hidden` for decorative required markers.
