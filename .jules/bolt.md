## 2024-05-24 - Throttling High-Frequency Events and Preventing Memory Leaks in Vue SPAs
**Learning:** Attaching anonymous functions to global events (like `window.addEventListener('scroll', ...)`) inside a Vue component's `mounted` hook without a corresponding cleanup in `unmounted` leads to severe memory leaks in Single Page Applications. The listener continues firing even after navigating away from the component. Furthermore, processing DOM reads (`getClientRects()`) on every scroll event frame without throttling blocks the main thread.
**Action:** Always extract global event listeners to named methods. Wrap the handler logic in `requestAnimationFrame` to decouple it from the event frequency, store the animation frame ID, and ensure BOTH the event listener and the pending animation frame are cancelled in the component's `unmounted` lifecycle hook. Also, prefer `getBoundingClientRect()` over `getClientRects()[0]` for single elements.
