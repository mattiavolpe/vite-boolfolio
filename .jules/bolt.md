## 2024-05-19 - Vue App Global Scroll Optimizations
**Learning:** In Single Page Applications built with Vue, attaching global `window.addEventListener('scroll')` without `passive: true` blocks scrolling, and without `requestAnimationFrame` it can lead to heavy layout thrashing on every scroll tick. Furthermore, failing to unbind these listeners in `unmounted()` leaks memory and runs unnecessary code on unmounted route components. Finally, using `getClientRects()[0]` without checking if the array is populated can crash when elements are unrendered; `getBoundingClientRect()` is safer.
**Action:** Always encapsulate global scroll logic in a method, attach with `{ passive: true }`, throttle logic with `requestAnimationFrame` tracked by a non-reactive property initialized in `created()`, and detach the listener in `unmounted()`.
